# Uso de software livre ou licenças viáveis

- Preferência por componentes open source (Python, FastAPI, Postgres, Apache Superset) reduzindo TCO e lock-in.
- Modelos de IA podem usar opções abertas ou serviços licenciados com cláusulas claras de proteção de dados.
- Licenciamento permissivo permite reutilização por outros entes federativos, ampliando o **impacto social**.
